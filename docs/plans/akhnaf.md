## 1. Decisions (approved)

| # | Decision | Choice |
|---|---|---|
| D1 | Client contract layer | **viem-only hooks** (`apps/web/lib/hive/`) — no wagmi, no React Query |
| D2 | Owner tx path | **Path A: Mera key as a direct viem signer**, faucet-funded, behind a `HiveSigner` interface; Kernel + Pimlico is a later swap |
| D3 | `register` ownership | User-signed from the canvas; contract takes `(name, agentType, agentPubKey)`; `owner = msg.sender` |
| D4 | Memory write auth | `setAgentWriter(agentId, writer)` owner-only; `write()` requires `msg.sender == writerOf(agentId)` |
| D5 | Propagation | Separate `PropagationEngine.sol`; `MemorySlots → PropagationEngine → KnowledgeGraph` |
| D6 | Topic encoding | `bytes32 keccak256` in storage; `string` in events + `hasPermission` |
| D7 | OpenZeppelin | Submodule; **`Ownable` only** (PropagationEngine wiring setter) |
| D8 | ABI/address delivery | Generated TS in `@hive/shared` + committed `deployments/monad-testnet.json` |
| D9 | Explorer naming | `explorerUrl` from `monadTestnet.blockExplorers` — **no "HashScan"** (that's Hedera) |
| D10 | Dev signer fallback | `HiveSigner` interface + dev-only raw-key signer behind an env flag |
